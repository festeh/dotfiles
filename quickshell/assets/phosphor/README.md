# Phosphor artwork

`book-open-duotone.svg` is from [Phosphor Icons](https://github.com/phosphor-icons/core/blob/main/assets/duotone/book-open-duotone.svg),
used as the Foliate workspace icon. The original `currentColor` fill is set to
`#cba6f7`, matching the bar's mauve accent and option 01 in the icon comparison.
The viewBox trims the original padding and centers the visible artwork, making
the book about 10% larger inside the same 18px icon slot.
