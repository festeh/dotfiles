# Layout lettermark

`ru.svg` is option 04, **RU letters**, from `previews/layout-icons.html`.
The letter shapes are outlined from JetBrains Mono Nerd Font Bold and filled
with `#cba6f7`, matching the bar's mauve accent. The SVG needs no installed font.

The font's SIL Open Font License and copyright notices are retained in `OFL.txt`.
